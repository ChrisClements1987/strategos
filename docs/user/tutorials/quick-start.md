# Quick Start Guide

Welcome to Strategos! This guide will walk you through creating your first portfolio and organizing your products.

## Step 1: Create Your First Portfolio

1. Launch Strategos
2. You'll see the **Portfolios** page
3. Click **"+ Create Portfolio"**
4. Fill in the form:
   - **Name**: e.g., "Enterprise Products 2025"
   - **Description**: Optional details about this portfolio
5. Click **Save**

## Step 2: Add Products

1. Click **Products** in the left sidebar
2. Select your portfolio from the dropdown
3. Click **"+ Create Product"** (feature coming soon)
4. Add product details:
   - Name, description, type (product or module)
   - Link to your portfolio

## Step 3: Define Features

1. Navigate to **Features** in the sidebar
2. Select a portfolio and product
3. Add features to your product with:
   - Name and description
   - Priority (low, medium, high, critical)
   - Status (planned, in_progress, completed)

## Step 4: Create Licences

1. Go to **Licences**
2. Select your portfolio
3. Create licence tiers (Standard, Pro, Enterprise)
4. Bundle features into each licence

## Step 5: Add Clients

1. Navigate to **Clients & Personas**
2. Define your target users:
   - Personas (user types)
   - Enterprise clients
   - Organizations

## Step 6: Track Requirements

1. Go to **Requirements**
2. Select a portfolio and client
3. Document client needs and feature requests
4. Track priority and approval status

## Tips

- **Navigate quickly**: Use the sidebar to jump between views
- **Filter intelligently**: All views support portfolio-based filtering
- **Data persistence**: Everything saves automatically to your local database
- **Privacy first**: All data stays on your machine
